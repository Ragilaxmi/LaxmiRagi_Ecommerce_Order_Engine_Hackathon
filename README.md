# 🛒 E-Commerce Order Engine (CLI)

## 📌 Overview
This project is a CLI-based backend simulation of an e-commerce system like Amazon/Flipkart.

## 🚀 Features
- Product Management (Add, View, Update stock)
- Multi-user Cart System
- Order Placement
- Payment Simulation (Success/Failure)
- Rollback System (on failure)
- Order Cancellation

## 🧠 Design Approach
- Modular structure (product, cart, order, payment)
- In-memory data storage
- CLI-based interaction

## ⚠️ Assumptions
- Data resets on restart (no database)
- Single system simulation

## ▶️ How to Run

```bash
python main.py
